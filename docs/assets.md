## Font files

The regular and bold fonts use version 5.01. The semibold font uses version 5.00.
The files contain Latin characters and the punctuation from the brief.
The font weights are 400, 600, and 700.
Each font rule checks the local font before the file URL.

## Sound files

Each event sound uses mono MP3 at 64 kbit/s.
The boot sound uses stereo MP3 at 96 kbit/s.
The Windows 7 archive stores the boot sound as `Startup.wav`.
Its `Windows Startup.wav` file lasts 0.217 seconds.
`startup.mp3` uses the 4.120 second boot sound from `Startup.wav`.

## Image dimensions

The Harmony wallpaper and logon background measure 1,920 by 1,200 pixels.
Each icon measures 48 by 48 pixels. The flower picture measures 128 by 128 pixels.
The Start orb sheet measures 108 by 324 pixels.
Each Start orb frame measures 108 by 108 pixels.
The sheet contains three frames. The order is normal, hover, pressed.

The source bitmap contains 105 frames of 200 by 200 pixels in one column.
The [source repository](https://github.com/powerCord1/windows-7-boot-html/blob/main/README.md) identifies `bootres.dll` as the bitmap source.
Frames 0, 50, and 104 match a [separate frame archive](https://github.com/peymanx/windows7_boot_animation_remake/tree/main/pieces) exactly.

The boot sprite uses seven columns and 15 rows. It measures 1,400 by 3,000 pixels.
Each frame measures 200 by 200 pixels. Frame indices start at zero.
Frames progress across each row, then to the next row.
Frame `i` has offsets `x = (i % 7) * 200` and `y = floor(i / 7) * 200`.

Each frame retains the original black background. The conversion uses `cwebp -q 80`.
All 105 frame positions match the source before compression.
The source bitmap has this SHA256 value.

The navigation sprite measures 232 by 29 pixels.
Each cell measures 29 by 29 pixels and contains the original 27 pixel image at offsets 1, 1.
Cells 0 through 3 contain Back in normal, hover, pressed, and disabled states.
Cells 4 through 7 contain Forward in the same state order.
The source bitmap IDs are 577, 578, 581, and 579, respectively.
The bitmap decoder retains the original 32 bit alpha channel.

The view sprite measures 128 by 16 pixels.
Its eight cells follow this order: Extra Large, Large, Medium, Small, List, Details, Tiles, Content.
The media sprite measures 180 by 108 pixels.
Its columns contain Previous, Play, Pause, Next, and Mute.
Its rows contain normal, hover, and pressed states.
Each media cell measures 36 by 36 pixels.
The Mute column uses the original crossed speaker glyph.
The sprite layouts match section 9 of `docs/explorer.md`.
